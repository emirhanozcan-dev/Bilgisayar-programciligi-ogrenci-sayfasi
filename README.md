
# Bilgisayar Programcılığı Öğrenci Sayfası

HTML5 ve CSS3 kullanılarak geliştirilmiş, bilgisayar
programcılığı öğrencilerine yönelik örnek bir web sitesi.

## Projenin Amacı

Bu proje, Web Tasarımı Temelleri dersi kapsamında
HTML ve CSS bilgilerimi geliştirmek ve uygulamalı
olarak öğrenmek amacıyla hazırlanmıştır.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- Visual Studio Code
- Git ve GitHub

## Proje Özellikleri

- Üniversite logosu ve başlık alanı
- Sayfa içi gezinme menüsü
- Bölüm hakkında bilgiler
- Haftalık ders programı
- Çalışma planı
- Etkinlik kayıt formu
- CSS ile sayfa tasarımı

## 🌐 Canlı Demo

[Web Sitesini Görüntüle](https://emirhanozcan-dev.github.io/Bilgisayar-programciligi-ogrenci-sayfasi/)

## Projeyi Çalıştırma

1. Repository dosyalarını indirin.
2. index.html dosyasını tarayıcıda açın.

## Not

Etkinlik kayıt formu yalnızca HTML form
elemanlarını öğrenmek amacıyla hazırlanmıştır.
Girilen bilgiler bir sunucuya kaydedilmez.
